마우스 / 패닝
  • 드래그: 화면 이동 (pan)
  • 휠: 커서 위치 기준 줌 인/아웃
  • 더블클릭: 해당 annotation 을 화면 중앙으로 이동
  • 오른쪽 하단 좌표: 씬 좌표(px) 실시간 표시
Annotation 그리기
  • 상단 툴바의 Polygon / Rectangle 버튼으로 모드 진입 (활성 시 하이라이트)
  • Polygon: 마우스를 누른 채 드래그하여 자유 경로를 그리고, 떼면 완성 (최소 3점, 자기교차 시 취소)
  • Rectangle: 드래그로 사각형 그리기 (떼면 완성)
  • 그리기 중 오른쪽 클릭 또는 Esc 로 모드 해제
Annotation 편집
  • 클릭: 선택 / 빈 공간 클릭: 선택 해제
  • 선택 후 꼭짓점 드래그: 모양 변형
  • annotation 위에서 드래그: 화면 이동
  • annotation은 클릭으로 선택하고, 선택 후 꼭짓점 드래그로 모양만 편집
  • Ctrl + polygon 선 근처 hover: 추가될 점 미리보기
  • Ctrl + polygon 선 근처 클릭: 점 추가
  • Delete: 선택한 annotation 삭제
  • Ctrl + S: annotation 저장
기타
  • Esc: 그리기 모드 취소, 편집 팝업 닫기
