Viewer UX Guide
Slide Navigation
  • Drag to pan the slide.
  • Use the mouse wheel to zoom around the cursor.
  • Double click an annotation to center it in the viewer.
  • The lower-right overlay shows the current slide coordinates in pixels.
Annotation Drawing
  • Use the toolbar buttons to enter Polygon, Brush, Rectangle, Point, fixed 1mm shape, Cut, or Ruler mode.
  • Polygon Brush: drag to paint a free path, then release to complete it.
  • Rectangle: drag to create a box and release to complete it.
  • Point: click once to place a point annotation.
  • Right click or press Esc to cancel the active drawing mode.
Annotation Editing
  • Click an annotation to select it.
  • Drag vertices to reshape the selected annotation.
  • Drag inside the selected annotation to move it.
  • Hold Ctrl while dragging to pan over annotations.
  • Press Delete to remove the selected annotation.
AI Result Cells
  • Alt + left click: edit the nearest visible result cell.
  • Alt + left drag: lasso-select visible result cells.
  • Alt + right click: add a new result cell at the clicked position.
  • Alt + right drag: lasso-select hidden Other cells and promote them to a visible class.
  • Alt + A: open the sticky class picker.
  • Ctrl + Z / Ctrl + Y: undo or redo cell edits.
Other
  • Esc: cancel drawing mode or close the active edit popup.
  • Use the AI Analysis help icon for model-specific guidance.
