- `04-upload/01-slide-upload.png`은 바깥 Home 화면과 팝업 브라우저 프레임을 제외하고 실제 Slide Upload 페이지 부분만 남겼습니다.

- `11-admin/04-login-activity.png`에는 사용자명, 접속 IP, 접속 위치가 표시되어 있습니다. 외부 공개용 매뉴얼에 사용한다면 비식별 처리를 권장합니다.
- 로그인 및 프로필 화면에도 예시 계정 정보가 포함되어 있으므로 공개 범위에 맞게 확인해야 합니다.
