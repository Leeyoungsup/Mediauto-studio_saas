# 실제 KNUCH ZIP의 계정별 폴더

KNUCH에서 PD-L1 프로젝트의 **비교 결과 ZIP**을 내려받아 압축을 푼 뒤, ZIP 안의 `계정별/<로그인 ID>/` 폴더들을 여기에 그대로 넣으세요. CSV를 재작성하거나 열 이름을 변경하지 않습니다.

```
계정별/
  로그인ID_A/
    비교결과.csv
    비교결과.json
  로그인ID_B/
    비교결과.csv
    비교결과.json
```

노트북은 CSV만 읽습니다. 읽는 판독값은 `CPS Grade`, `전문의 판독시간(초)`, `AI 판독시간(초)`입니다. 프로젝트·모델·계정·슬라이드 및 측정 ID/시각은 매칭과 최신 기록 선택에 사용합니다. CSV의 CPS 점수, AI 점수/Grade와 JSON은 계산에 사용하지 않습니다.

`CPS Grade`의 내보내기 문자열 `CPS < 1`, `1 ≤ CPS < 10`, `CPS ≥ 10`을 내부적으로 0/1/2로 변환합니다. 반복 판독은 측정 시각, 측정 ID 순으로 최신 기록을 선택합니다.

이 폴더에는 가상 계정 데이터를 넣지 않았습니다. 형식 검증용 가상 예제는 별도 `../examples/knuch_zip_export/계정별`에 있습니다. 실제 ZIP 데이터는 아직 제공되지 않았습니다.
