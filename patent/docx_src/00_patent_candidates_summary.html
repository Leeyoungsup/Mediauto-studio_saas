MeDICus Studio SaaS 특허 출원 후보 요약

본 문서는 변리사 검토 및 출원 전략 수립을 위한 기술 정리 초안이다. 최종 청구범위, 선행기술 조사, 출원국별 보정 전략은 변리사 검토를 통해 확정한다.

1. 출원 후보 개요

번호 출원 후보 명칭 핵심 기술적 과제 권장 형태
1 WSI Viewer 및 Adaptive Tile Streaming 방법 대용량 병리 슬라이드를 웹 환경에서 부드럽게 탐색하고, 복수 사용자의 동시 접속 상황에서도 현재 viewport 중심의 타일을 우선 표시하는 방법 방법 + 시스템 + 컴퓨터 판독 가능 기록매체 청구항

2. 권장 출원 우선순위

  1. WSI Viewer 및 Adaptive Tile Streaming 방법: 제품 전체 사용감과 서버 확장성의 기반 기술이며, 일반적인 슬라이드 로딩 자체가 아니라 viewport 기반 queue, fallback, abort, hybrid miss handling, multi-user scheduling을 결합한 점을 강조한다.
  2. Virtual Stain 생성 및 WSI Overlay 표시 방법: 의료 AI 제품으로서 독립적 차별성이 크고, 모델 결과를 WSI viewer에서 실제 진단 보조 형태로 제공하는 방법을 포함한다.
  3. AI-assisted WSI Annotation Workflow: 병리 데이터 생성, 검수, AI assistance, 사용자 수정 이력을 하나의 workflow로 연결한다.
  4. 대규모 병리 AI 정량 결과의 실시간 시각화 방법: Quanti 모델 결과 표시 기술로 중요하나, viewer 기술과 일부 중복될 수 있으므로 청구항 경계를 명확히 한다.

3. 출원 후보별 핵심 청구 포인트

3.1 WSI Viewer 및 Adaptive Tile Streaming 방법

  • viewport, zoom level, pan direction에 따라 표시 대상 타일을 산출하고 우선순위를 부여하는 구성
  • 캐시 hit, 캐시 miss, 서버 부하, background tiling 상태에 따라 inline generation과 queued generation을 전환하는 구성
  • 요청 중인 타일이 늦어지는 경우 parent tile, thumbnail, blank fallback을 이용해 화면 공백과 interaction blocking을 줄이는 구성
  • slide 변경 또는 viewport 변경 시 stale request를 abort하고 새로운 viewport 기준으로 tile queue를 재정렬하는 구성
  • inline generation 허용 조건, queue 부하 판단 기준, priority score, tile level별 timeout, generation id 폐기 규칙, multi-user priority 충돌 처리 규칙

3.2 대규모 병리 AI 정량 결과의 실시간 시각화 방법

  • AI detection 결과를 WSI 좌표계의 spatial index로 구성하고 viewport와 교차하는 결과만 렌더링하는 구성
  • class visibility, confidence threshold, heatmap, patch overlay, hidden cell display를 실시간 반영하는 구성
  • zoom level과 표시 밀도에 따라 cell, patch, heatmap 렌더링 방식을 전환하는 구성

3.3 Virtual Stain 생성 및 WSI Overlay 표시 방법

  • WSI를 patch 단위로 추론하고 overlap 영역을 blending하여 virtual stain canvas 또는 tile set을 생성하는 구성
  • virtual stain 결과를 tile pyramid로 변환하여 원본 WSI와 동일 viewport 좌표계에서 streaming하는 구성
  • 원본과 virtual stain 결과를 opacity overlay 또는 split view로 정렬 표시하는 구성
  • patch 크기 및 overlap 결정, blending weight 수식, MPP 차이 보정, source signature 기반 cache invalidation, 부분 추론 결과의 tile 단위 우선 표시

3.4 AI-assisted WSI Annotation Workflow

  • required region 지정, patch task 생성, cell assistance, human correction을 하나의 작업 흐름으로 연결하는 구성
  • WSI annotation, patch annotation, cell annotation을 동일 좌표계와 상태 모델로 관리하는 구성
  • 사용자 수정 이력, undo/redo, audit, AI 결과 보정 데이터를 후속 분석에 반영하는 구성
  • correction dataset, QA status, re-review queue, retraining export, AI-human difference statistics, worker audit report 등 실제 갱신 데이터

3.5 대규모 병리 AI 정량 결과의 실시간 시각화 방법의 보강 포인트

  • 낮은 배율에서는 aggregate 또는 heatmap, 높은 배율에서는 cell bbox 또는 point로 전환하는 단계별 표현
  • patch, cell, heatmap, biomarker score를 동일 WSI 좌표계에서 연동 표시하는 구성
  • confidence/class filter 변경 시 spatial index를 재생성하지 않고 rendering 조건만 갱신하는 구성
  • 사용자 correction 발생 시 전체 index rebuild 없이 해당 bucket만 부분 갱신하는 구성

4. 변리사 상담 시 확인할 항목

  • 각 후보를 단일 출원으로 진행할지, continuation/divisional 가능성을 고려해 넓게 최초 출원할지
  • 소프트웨어 발명으로서 추상 아이디어 거절을 피하기 위해 어떤 구체적 컴퓨팅 개선 효과를 전면에 둘지
  • OpenSeadragon, QuPath, ASAP, PathPresenter, digital pathology viewer 관련 선행기술 대비 차별 포인트
  • AI 모델 자체, inference pipeline, viewer 표시 방법 중 어느 범위를 독립항으로 둘지
  • 국내, PCT, 미국 출원 순서와 공개 전 출원 일정
