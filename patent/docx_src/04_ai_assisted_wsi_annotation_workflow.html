AI-assisted WSI Annotation Workflow

1. 발명의 명칭

Whole Slide Image annotation, patch labeling 및 AI assistance를 결합한 병리 영상 주석 workflow 방법

2. 기술분야

본 발명은 디지털 병리 annotation, WSI labeling workflow, patch-based labeling, cell-level AI assistance, human-in-the-loop correction, annotation state management에 관한 것이다.

3. 배경기술 및 문제점

병리 AI 모델 개발 및 검수에는 WSI 단위 annotation, ROI annotation, patch labeling, cell-level correction 등 다양한 수준의 labeling 작업이 필요하다. 기존 도구에서는 전체 WSI annotation과 patch 작업, AI result correction이 서로 분리되어 있어 사용자가 반복적으로 좌표를 맞추고 상태를 관리해야 한다.

또한 AI assistance가 제공되더라도 사용자의 required region, patch 상태, cell edit 결과와 연결되지 않으면 실제 검수 workflow에서 활용도가 낮아진다. 대용량 WSI 상에서 annotation을 편집할 때 undo/redo, merge, cut, class 변경, audit까지 안정적으로 관리하는 것도 어렵다.

4. 해결하고자 하는 과제

  • WSI annotation, patch task, cell-level assistance를 하나의 좌표계와 상태 모델로 연결하는 것
  • 사용자가 required region을 지정하면 patch labeling task를 자동으로 구성하는 것
  • AI assistance가 patch 또는 cell 후보를 제안하고 사용자가 이를 검수/수정하는 것
  • 사용자 수정 이력과 AI 결과를 후속 분석, 검수, audit에 반영하는 것
  • annotation 편집 도구를 WSI viewer interaction과 충돌 없이 제공하는 것

5. 발명의 구성

5.1 WSI annotation 도구부

viewer는 polygon, brush, rectangle, point, ruler 등 복수의 annotation 도구를 제공한다. 각 annotation은 WSI scene coordinate, class, color, visibility, selected state, group 정보로 저장된다.

5.2 Required region 및 patch task 생성부

사용자는 WSI 상에서 required region을 지정할 수 있다. 시스템은 required region과 grid 또는 patch size 조건에 기초하여 labeling 대상 patch를 생성한다. patch list는 labeling status, assigned user, result count, assistance state와 연결된다.

5.3 Cell-level AI assistance부

AI assistance는 WSI 또는 patch 영역 내 cell 후보, label 후보, segmentation 후보 또는 review 대상 후보를 생성한다. 생성된 assistance result는 patch coordinate와 WSI coordinate 양쪽에서 참조 가능하도록 저장된다.

5.4 Human correction 및 feedback부

사용자는 AI assistance 결과를 수락, 삭제, class 변경, 위치 수정, 병합, 분할할 수 있다. 수정된 결과는 AI output과 별도 layer 또는 override layer로 관리되며, 후속 분석 또는 검수 보고서에 반영된다.

5.5 Undo/redo 및 audit state 관리부

annotation 생성, 수정, 삭제, merge, cut, class 변경 등 사용자 action은 undo/redo stack과 audit log로 관리된다. 이를 통해 판독 중 실수 복구와 작업 이력 추적이 가능하다.

5.6 통합 viewer workflow부

annotation layer, AI result layer, patch boundary, required region, selected cells는 동일 viewer coordinate system에서 표시된다. 사용자는 WSI 전체 화면, patch list, cell assistance panel 사이를 이동하면서 동일한 annotation state를 유지한다.

6. 동작 절차

  1. 사용자가 WSI viewer에서 annotation mode를 선택한다.
  2. 사용자는 polygon, brush 또는 rectangle 도구로 ROI 또는 required region을 생성한다.
  3. 시스템은 required region을 기준으로 patch grid를 산출하고 patch labeling task를 생성한다.
  4. AI assistance task가 patch 또는 WSI 영역에 대해 cell 후보 또는 labeling 후보를 생성한다.
  5. 생성된 후보는 WSI coordinate와 patch coordinate에 매핑되어 viewer에 표시된다.
  6. 사용자는 후보를 검수하고 수정하며, 수정 이력은 undo/redo stack과 audit record에 반영된다.
  7. 완료된 annotation과 correction은 후속 AI 분석, report, model feedback 또는 QA workflow에 전달된다.

7. 효과

  • WSI annotation, patch labeling, cell assistance가 분리되지 않고 하나의 workflow로 연결된다.
  • required region 기반 patch task 생성으로 labeling 대상을 명확히 관리할 수 있다.
  • AI assistance와 human correction이 연결되어 labeling 효율과 검수 품질을 높인다.
  • 동일 좌표계 기반으로 WSI level과 patch level 사이의 이동 및 결과 동기화가 가능하다.
  • undo/redo 및 audit 관리로 임상/연구 검수 환경에 필요한 traceability를 제공한다.

8. 청구항 초안

독립항 예시

Whole Slide Image annotation workflow를 제공하는 방법에 있어서, WSI viewer에서 사용자 입력에 따라 required region annotation을 생성하는 단계; 상기 required region에 기초하여 복수의 patch labeling task를 생성하는 단계; AI assistance model을 이용하여 상기 required region 또는 patch 영역 내 cell 또는 label 후보를 생성하는 단계; 상기 후보를 WSI coordinate 및 patch coordinate에 매핑하여 viewer에 표시하는 단계; 사용자의 수정 입력에 따라 상기 후보 또는 annotation을 갱신하는 단계; 갱신된 annotation 및 수정 이력을 후속 분석 또는 검수 workflow에 반영하는 단계를 포함하는 방법.

종속항 후보

  • required region과 patch grid의 교차 여부에 따라 patch task를 생성하는 방법
  • AI assistance result를 patch coordinate와 WSI coordinate 양쪽에 저장하는 방법
  • 사용자 수정 입력을 override layer로 저장하고 원본 AI result와 구분하는 방법
  • annotation edit action을 undo/redo stack 및 audit log로 관리하는 방법
  • WSI viewer의 pan/zoom 상태와 patch list selection을 동기화하는 방법

9. 선행기술 대비 차별 포인트

  • 단순 annotation tool이 아니라 required region, patch task, AI assistance, human correction을 하나의 workflow로 결합한다.
  • WSI 좌표계와 patch 좌표계를 동시에 유지하여 결과 동기화와 검수를 지원한다.
  • AI assistance 결과를 사용자가 수정한 feedback layer와 연결하여 후속 분석에 활용한다.
