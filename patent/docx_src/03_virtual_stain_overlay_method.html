Virtual Stain 생성 및 WSI Overlay 표시 방법

1. 발명의 명칭

Whole Slide Image 기반 Virtual Stain 결과의 생성, 타일화 및 원본 슬라이드 정렬 표시 방법

2. 기술분야

본 발명은 디지털 병리 영상, AI 기반 virtual staining, WSI patch inference, image blending, tile pyramid generation, 원본-가상염색 overlay viewer에 관한 것이다.

3. 배경기술 및 문제점

Virtual stain 기술은 하나의 염색 슬라이드로부터 다른 염색 결과를 예측함으로써 추가 염색 비용과 시간을 줄일 수 있다. 그러나 WSI는 매우 크기 때문에 전체 이미지를 한 번에 AI 모델에 입력하기 어렵고, patch 단위로 추론하면 patch 경계에서 artifact 또는 intensity discontinuity가 발생할 수 있다.

또한 virtual stain 결과를 단일 큰 이미지로 생성하더라도 웹 viewer에서 원본 WSI와 정확히 정렬하여 pan/zoom, opacity overlay, split view로 표시하려면 별도의 tile pyramid와 coordinate alignment가 필요하다.

4. 해결하고자 하는 과제

  • WSI를 patch 단위로 추론하면서 patch boundary artifact를 줄이는 것
  • virtual stain 결과를 WSI viewer에서 원본과 동일 좌표계로 표시하는 것
  • large virtual stain result를 tile pyramid cache로 변환하여 on-demand streaming하는 것
  • 미처리 영역, 불확실 영역, tissue 외부 영역을 안정적으로 처리하는 것
  • 원본과 virtual stain을 overlay 또는 split view로 자연스럽게 비교하는 것

5. 발명의 구성

5.1 Patch extraction 및 inference부

입력 WSI는 level-0 또는 선택된 resolution의 좌표계에서 일정 크기 patch로 분할된다. 각 patch는 tissue mask, ROI, required region 또는 전체 slide 조건에 따라 선택된다. 선택된 patch는 virtual stain AI model에 입력되어 대응하는 stain output patch를 생성한다.

5.2 Overlap blending부

인접 patch 간에는 overlap 영역을 설정하고, Gaussian 또는 distance-based blending weight를 적용한다. output canvas에는 각 patch output과 blending weight가 누적되며, 최종 pixel value는 weighted average로 계산된다. 이를 통해 patch 경계의 seam artifact를 줄인다.

5.3 Uncovered 및 uncertainty 처리부

추론되지 않은 영역 또는 tissue 외부 영역은 uncovered mask로 관리된다. viewer 표시 시 해당 영역은 원본 이미지, 투명 영역, neutral background 또는 uncertainty overlay로 표시될 수 있다. 이 구성은 virtual stain 결과를 실제 판독 화면에 표시할 때 잘못된 확신을 줄인다.

5.4 Tile pyramid cache 생성부

생성된 virtual stain canvas 또는 patch stream 결과는 viewer tile size에 맞게 level-0 tile로 저장되고, 하위 resolution level의 tile pyramid가 생성된다. 각 tile은 stain type, target MPP, source slide signature, ROI metadata와 함께 cache된다.

5.5 Overlay 및 split view 표시부

viewer는 virtual stain tile pyramid를 원본 slide coordinate system에 정렬하여 표시한다. 사용자는 opacity를 조절하여 원본 위에 virtual stain을 overlay하거나, split view handle을 움직여 원본과 virtual stain을 좌우 또는 영역별로 비교할 수 있다.

5.6 Cache 재사용 및 상태 관리부

virtual stain 결과가 이미 생성되어 있고 source slide signature와 parameter가 일치하면 기존 cache를 재사용한다. 결과가 없거나 stale이면 inference task를 생성하고 progress 및 tile availability를 viewer에 표시한다.

6. 구체적 처리 조건 및 수식 예시

6.1 Patch 크기 및 overlap 결정 방식

patch 크기는 모델 입력 크기, 목표 MPP, GPU memory, tissue mask 해상도에 따라 결정한다. 예를 들어 모델 입력이 512x512 또는 1024x1024 pixel이면, WSI level-0 좌표계에서 target MPP와 source MPP의 비율을 반영하여 read region 크기를 산출한다.

overlap은 patch size의 일정 비율 또는 고정 pixel 폭으로 설정할 수 있다. 예를 들어 overlap 폭은 patch width의 10~25% 또는 64~256 pixel 범위에서 설정된다. tissue boundary 또는 high-detail region에서는 overlap을 크게 하고, 균질한 background 영역에서는 overlap을 줄일 수 있다.

6.2 Blending weight 수식 예시

각 patch output은 중심부에 높은 weight를 부여하고 경계부로 갈수록 낮은 weight를 부여한다. 예시적으로 patch 내 pixel 좌표 (u, v)에 대해 좌우 및 상하 경계까지의 정규화 거리 d(u, v)를 계산하고, 다음과 같은 weight를 사용할 수 있다.

w(u,v) = max(epsilon, min(1, distance_to_edge(u,v) / overlap_width))

또는 Gaussian 형태로 다음과 같이 정의할 수 있다.

w(u,v) = exp(-((u-cx)^2 + (v-cy)^2) / (2*sigma^2))

최종 virtual stain pixel은 누적 output과 누적 weight의 비율로 계산한다.

V(x,y) = sum_i(w_i(x,y) * P_i(x,y)) / max(epsilon, sum_i(w_i(x,y)))

6.3 좌표 변환 방식

source WSI의 level-0 좌표를 기준 좌표계로 사용한다. patch 추출 좌표 (x0, y0), source MPP, target MPP, model input size를 이용하여 model output pixel이 WSI 좌표계의 어느 영역에 대응하는지 계산한다. model output pixel (u, v)의 WSI 좌표는 다음과 같이 표현할 수 있다.

X = x0 + u * output_mpp / source_mpp

Y = y0 + v * output_mpp / source_mpp

viewer 표시 시에는 virtual stain tile의 origin, scene width, scene height, tile level downsample을 metadata로 저장하여 원본 WSI tile과 동일한 scene coordinate에 배치한다.

6.4 MPP가 다를 때의 정렬 방식

입력 슬라이드 MPP와 virtual stain target MPP가 다르면, virtual stain 결과의 pixel spacing을 metadata에 저장하고 viewer에서 scene coordinate scaling을 적용한다. 원본 WSI 좌표계의 특정 위치 (X, Y)는 virtual stain image 좌표계에서 다음과 같이 변환된다.

u = (X - originX) * source_mpp / target_mpp

v = (Y - originY) * source_mpp / target_mpp

이 변환을 tile level별 downsample과 결합하여 overlay 및 split view에서 원본과 virtual stain의 위치를 동기화한다.

6.5 Cache invalidation 방식

virtual stain cache는 source slide signature, source filename, source file size, source modification time, model id, model version, target stain type, target MPP, ROI, preprocessing parameter, blending parameter를 포함하는 metadata로 검증한다. 이 중 하나라도 변경되면 기존 cache를 stale로 판단하고 재추론 또는 부분 재생성을 수행한다.

6.6 부분 추론 결과의 tile 단위 우선 표시

전체 virtual stain inference가 완료되기 전에도, 이미 생성된 patch 또는 tile은 tile pyramid의 일부로 먼저 저장될 수 있다. viewer는 tile metadata에서 available tile set을 확인하고, 생성된 virtual stain tile만 overlay로 표시한다. 미생성 영역은 원본 tile 또는 uncovered mask로 표시한다. 이를 통해 사용자는 전체 inference 완료 전에도 일부 결과를 확인할 수 있다.

7. 동작 절차

  1. 입력 WSI와 target stain type, target MPP, ROI 조건을 수신한다.
  2. source slide signature와 기존 virtual stain cache metadata를 비교한다.
  3. cache가 유효하면 tile pyramid를 viewer에 연결한다.
  4. cache가 없으면 WSI에서 patch 좌표를 산출하고 tissue/ROI 조건에 따라 patch를 추출한다.
  5. 각 patch를 AI model에 입력하여 virtual stain patch를 생성한다.
  6. patch output을 blending weight와 함께 output canvas 또는 streaming tile buffer에 누적한다.
  7. 최종 virtual stain 결과를 tile pyramid로 저장한다.
  8. viewer에서 원본 tile과 virtual stain tile을 동일 좌표계에 정렬하여 overlay 또는 split view로 표시한다.

8. 효과

  • WSI 전체를 한 번에 처리하지 않고 patch 단위로 추론하여 대용량 슬라이드 처리가 가능하다.
  • overlap blending으로 patch 경계 artifact를 줄일 수 있다.
  • tile pyramid cache를 통해 virtual stain 결과를 일반 WSI tile처럼 빠르게 탐색할 수 있다.
  • 원본과 virtual stain을 동일 viewer에서 overlay/split view로 비교하여 판독 효율을 높인다.
  • cache metadata를 이용해 stale result를 방지하고 재사용성을 높인다.

9. 청구항 초안

독립항 예시

Whole Slide Image로부터 virtual stain 결과를 생성하여 표시하는 방법에 있어서, 입력 WSI의 좌표계에서 복수의 patch 좌표를 산출하는 단계; 상기 patch 좌표에 따라 WSI patch를 추출하는 단계; 상기 WSI patch를 virtual stain model에 입력하여 stain output patch를 생성하는 단계; 인접 patch 간 overlap 영역에 blending weight를 적용하여 virtual stain output을 누적하는 단계; 누적된 virtual stain output으로부터 tile pyramid cache를 생성하는 단계; 상기 tile pyramid cache를 원본 WSI 좌표계에 정렬하여 viewer에서 overlay 또는 split view로 표시하는 단계를 포함하는 방법.

종속항 후보

  • overlap 영역에 Gaussian 또는 distance-based weight를 적용하는 방법
  • uncovered 영역을 mask로 관리하고 viewer에서 별도 표시하는 방법
  • source slide signature와 target stain parameter를 이용해 virtual stain cache validity를 판단하는 방법
  • virtual stain tile을 원본 WSI tile과 동일 pan/zoom event에 동기화하여 표시하는 방법
  • split view handle 위치에 따라 원본 tile과 virtual stain tile의 표시 영역을 동적으로 분할하는 방법

10. 선행기술 대비 차별 포인트

  • 모델 추론만이 아니라 WSI patch inference, blending, tile pyramid cache, viewer overlay를 하나의 방법으로 결합한다.
  • 원본 WSI와 virtual stain 결과를 동일 coordinate system에서 interactive하게 비교 표시한다.
  • uncovered/uncertainty 영역 및 cache validity를 viewer workflow에 포함한다.
