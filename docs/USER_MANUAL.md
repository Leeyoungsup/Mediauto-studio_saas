# MeDIAuto Studio — 사용자 매뉴얼

> 화면 단위 step-by-step 조작 안내. 각 `## ` 헤더는 PPT 슬라이드 1장 분량.
>
> 대상: 병리의·연구원·관리자 / 버전: 1.0.0 / 갱신: 2026-05-04

---

## 1. 표지

- **MeDIAuto Studio 사용자 매뉴얼**
- 디지털 병리 WSI 뷰어 + AI 분석
- 처음 사용자부터 관리자까지
- 본 매뉴얼은 화면 조작 중심 — 의도된 사용/한계는 [GUIDELINE.md](GUIDELINE.md) 참조

---

## 2. 시작하기 전에 — 준비물

- 병원이 발급한 서버 주소 (예: `https://medicus.hospital.local:8091`)
- 발급된 계정 (없으면 회원가입 → 관리자 승인)
- 권장 브라우저: Chrome / Edge / Safari 최신
- 안정적인 인터넷 (대용량 슬라이드 업로드 시)
- (선택) Google Authenticator 앱 — 2차 인증 사용 시

---

## 3. 빠른 시작 (5분 안에)

1. 브라우저로 서버 주소 접속
2. 로그인 (또는 회원가입 → 승인 대기)
3. 좌측 폴더에서 슬라이드 클릭 → 뷰어 자동 열림
4. 마우스 휠로 줌, 드래그로 팬
5. 우측 패널에서 AI 모델 클릭 → 분석 시작
6. 결과를 "Visualize" 또는 "PDF Export"

---

## 4. 화면 구성

```

├──────────┬──────────────────────────┬───────────────────┤
│  좌측    │                          │   우측            │
```

- 모바일·태블릿(≤900px): 좌·우 패널은 햄버거 토글로 drawer 형태

---

## 5. 화면 — 로그인

- URL 직접 입력 또는 시작 페이지의 "로그인" 클릭
- 입력: **아이디** + **비밀번호**
- MFA 활성 사용자는 **6자리 TOTP 코드** 추가 입력
- "로그인 유지" 체크 시 7일 자동 로그인 (Refresh Token)
- 5회 실패 시 30분 자동 잠금 → 잠금 해제는 관리자에게 요청

---

## 6. 화면 — 회원가입

1. 로그인 페이지에서 "회원가입" 클릭
2. **아이디** (4~30자, 영문·숫자·언더스코어)
3. **비밀번호** (8자+, 대·소·숫자·특수문자 모두 포함)
4. **이름** (한글/영문)
5. **부서** (선택)
6. "가입" 클릭 → "관리자 승인 대기" 메시지
7. 관리자가 승인하면 이메일 또는 사내 알림 수신 (시스템 설정 따라 다름)
8. 첫 가입자는 자동으로 admin + 즉시 로그인 가능

---

## 7. 2차 인증 (MFA) — 활성화

1. 로그인 후 우상단 사용자 메뉴 → "2차 인증 설정"
2. "QR 코드 받기" 클릭 → 화면에 QR 코드 표시
3. 휴대폰의 Google Authenticator (또는 동등 앱) 으로 QR 스캔
4. 앱에 표시된 6자리 코드를 입력란에 입력 → "활성화"
5. 다음 로그인부터 비밀번호 + TOTP 코드 모두 필요

> 휴대폰 분실 시 관리자에게 비활성화 요청 → 새 디바이스로 재설정.

---

## 8. 비밀번호 변경

1. 우상단 사용자 메뉴 → "비밀번호 변경"
2. 현재 비밀번호 입력
3. 새 비밀번호 입력 (정책: 대·소·숫자·특수문자 8자+)
4. 확인 입력
5. "변경" 클릭 → **모든 기기에서 자동 로그아웃** 됨 (재로그인 필요)

---

## 9. 슬라이드 업로드 — 1단계: 폴더 선택

1. 좌측 폴더 트리에서 업로드 대상 폴더 클릭
2. 폴더가 없으면 "+ 폴더" 버튼으로 새로 만들기
3. 폴더명은 진단·연구 단위로 의미 있게 (예: `HnE(BR)`, `IHC(PD-L1)`)
4. 좌측 상단 "업로드" 버튼 클릭 → 업로드 다이얼로그 열림

---

## 10. 슬라이드 업로드 — 2단계: 파일 선택·전송

- **drag-and-drop**: 다이얼로그 영역에 파일 끌어다 놓기
- **파일 선택기**: "파일 선택" 클릭 → 다중 선택 가능
- 지원 형식: SVS, NDPI, TIFF, VMS, VMU, SCN, MRXS (최대 20 GB)
- 5 MB 청크 단위 자동 전송 — 네트워크 끊겨도 재개
- 진행률 바로 % 확인
- 업로드 완료 → 자동 타일 프리젠 + SHA-256 체크섬 계산

---

## 11. 슬라이드 — 처음 열기

1. 좌측 그리드에서 썸네일 클릭
2. 우측 화면에 로딩 오버레이 (3-stage 타일 다운로드 진행률)
3. 100% 완료 → 뷰어가 표시되며 자동 Fit-to-window
4. 좌하단 미니맵에 전체 슬라이드 위치 표시
5. 우상단 "슬라이드 정보" 버튼 → 메타데이터 (배율·MPP·크기) 확인

---

## 12. 뷰어 조작 — 줌·팬·Fit

| 동작 | 데스크톱 | 모바일 |
|------|---------|-------|
| 팬 | 좌클릭 + 드래그 | 한 손가락 드래그 |
| 줌 인/아웃 | 마우스 휠 (커서 위치 기준) | 두 손가락 핀치 |
| Fit to window | 툴바 "Fit" 버튼 | 같은 버튼 |
| 미니맵 클릭 | 클릭한 위치로 즉시 이동 | 같음 |
| 키보드 + / − | 줌 인/아웃 | — |

> 마우스 좌표는 우하단 오버레이에 슬라이드 픽셀 단위로 표시.

---

## 13. Annotation — Polygon (lasso) 그리기

1. 툴바에서 **Polygon** 버튼 클릭 (선택 시 강조 표시)
2. 슬라이드 위에서 마우스 좌클릭 + 드래그 → 따라 그리기
3. 마우스 떼면 자동 완료 (10 px 간격으로 점이 자동 추가됨)
4. 우측 Annotation 패널에 새 항목 추가 → 이름·색상 변경 가능
5. 그리기 취소: 우클릭 또는 ESC

> 최소 3점 + 자기 교차 폴리곤은 자동 거부.

---

## 14. Annotation — 사각형·점·1mm² ROI

- **Rectangle**: 툴바 → 드래그로 사각형 / 마우스 떼면 완성
- **Point**: 툴바 → 클릭한 자리에 즉시 점 생성
- **1mm² 사각형 / 원형**: 정확히 1 mm² 면적의 ROI 자동 그리기 (양적 분석용)
- **Ruler**: 두 점 클릭 → 거리 표시 (μm)
- viewer 역할은 위 도구 사용 가능하지만 **저장은 불가**

---

## 15. AI 분석 — HE-Fit 실행

1. H&E 슬라이드를 연 상태에서 우측 패널 "HE-Fit" 탭
2. **조직 타입 선택**: Stomach / Breast / Other
3. (선택) ROI 폴리곤 그려둔 상태면 그 영역만 분석됨
4. "분석 시작" 버튼 클릭
5. 진행률 바: 모델 로딩 → 조직 마스크 → 패치 추론 → Epithelial 재분류
6. 완료 시 슬라이드 위에 세포 점 오버레이 + 우측 클래스별 카운트 표시

---

## 16. AI 분석 — PD-Score (PD-L1)

1. PD-L1 IHC 슬라이드 열기
2. 우측 패널 "PD" 탭
3. **조직 타입**: Stomach (CPS) / Lung (TPS)
4. "분석 시작" → 약 5–15분 소요 (GPU 기준)
5. 완료 시 우상단에 **CPS 또는 TPS 점수** 표시 (게이지 + 숫자)
6. "Visualize" → Score Card 탭에 자세한 분포

---

## 17. AI 분석 — Precise-IHC

1. IHC 슬라이드 열기
2. 우측 패널 "IHC" 탭
3. **Marker 선택**: HER2 / ER_PR / KI_67
4. "분석 시작" → 진행률 표시
5. 완료 시 marker 별 점수
   - **HER2**: 0–3.0 가중평균 + dominant class
   - **ER/PR**: Allred PS·IS·TS (Positive 여부)
   - **Ki-67**: Labeling Index (%) + High/Low 판정 (cutoff 14%)

---

## 18. AI 분석 — VS-IHC (Virtual Staining)

1. H&E 슬라이드 열기
2. 우측 패널 "VS" 탭
3. **Stain Type**: ihc_membrane / ihc_nucleus
4. **Target MPP** 설정 (기본 2.0 — 낮을수록 고해상도, 더 오래 걸림)
5. "분석 시작" → 결과는 가상 IHC 타일 피라미드로 저장됨
6. 뷰어 토글 — 원본 / VS / Split view 전환
7. 결과는 연구·교육용 — 실제 IHC 염색 대체 아님

---

## 19. AI 결과 — 셀 편집

1. 결과가 표시된 후 우측 결과 리스트에서 클래스 선택
2. **edit 모드**: 셀을 클릭 → 클래스 변경 다이얼로그
3. **multi 모드**: 드래그로 여러 셀 선택 → 일괄 변경
4. **add 모드**: 빈 위치 클릭 → 새 셀 추가 (현재 sticky 클래스로)
5. **Sticky HUD**: Shift 키 홀드 → 마우스 우상단에 현재 클래스 색상 + 이름 표시
6. **삭제**: edit/multi 모드에서 Delete 또는 D 키
7. 점수(HER2/Allred/CPS/Ki-67)는 셀 변경 즉시 재계산

---

## 20. AI 결과 — 저장·불러오기

- "Save" 버튼 → 본인 사용자 전용 편집본으로 저장
  - 원본 추론 캐시는 절대 건드리지 않음
  - 저장 위치: 사용자별 분리 (`AI_RESULTS_DIR/user_edits/{user_id}/...`)
- "Load" 버튼 → 같은 슬라이드의 저장본 보유 사용자 목록
- 다른 사용자 편집본 선택 시 그 결과로 화면 갱신
- 본인 편집본만 삭제 가능 (타인 것은 거부됨)

---

## 21. AI 결과 — Visualize 다이얼로그

1. 결과 패널 하단 "Visualize" 클릭
2. 4개 탭으로 시각화
   - **Class Distribution**: 클래스별 카운트 바 차트
   - **Tumor Analysis**: Tumor / Benign 비율 (HE-Fit Stomach/Breast)
   - **Spatial Heatmap**: 썸네일 + 클래스별 오버레이
   - **Confidence Distribution**: confidence 히스토그램
3. "이미지 저장" / "클립보드 복사" 지원

---

## 22. AI 결과 — PDF 리포트 출력

1. Visualize 다이얼로그 또는 결과 패널에서 "PDF Export"
2. 자동 생성 항목:
   - 표지 (슬라이드명 / 분석 모델 / 점수 메트릭)
   - 슬라이드 프리뷰 + ROI
   - 클래스별 카운트 표
   - Score Card (HER2 / Allred / CPS / TPS / Ki-67 별 전용 페이지)
3. 파일명 자동: `{slide_stem}_{model}_{variant}_{date}.pdf`
4. 다운로드 폴더로 저장

---

## 23. 폴더 자동 AI 추론 설정

1. 좌측 폴더 트리에서 폴더 우클릭 → "자동 AI 설정"
2. 작업 추가 (예: HE-Fit · Stomach)
3. 여러 작업 동시 등록 가능 (HE-Fit + PD-Score + Precise-IHC + VS-IHC)
4. "Enable" 체크 → 60초 주기 백그라운드 워커가 미완 슬라이드 자동 처리
5. 사용자 활동 / 업로드 중에는 자동 양보
6. viewer 역할은 설정 변경 불가 (조회만 가능)

---

## 24. 색 보정 — Hamamatsu NDP fit 토글

- Hamamatsu NDPI 슬라이드는 **NDP.view2** 와 톤이 다를 수 있음
- 우측 패널 "NDP 색보정" 토글 ON
- URL 이 `/ndp/` 서브경로로 전환되어 톤 매칭된 타일이 서빙됨
- 첫 토글 시 약간 느림 (서버에서 변형 캐시 생성) → 이후엔 정적 서빙
- 썸네일도 같이 보정됨

## 26. 관리자 — 사용자 승인

1. 우상단 메뉴 → "관리자 페이지" (admin 만 표시됨)
2. "승인 대기" 탭 클릭 → 신규 가입자 목록
3. 행에서 역할 선택 (viewer / doctor / admin)
4. **승인** 또는 **거부** 클릭
5. 거부 시 사유 입력 → 감사 로그에 보존
6. 승인 즉시 해당 사용자 로그인 가능

---

## 27. 관리자 — 활동 로그 조회

1. 관리자 페이지 → "활동 로그" 탭
2. 컬럼: 시간(KST) · 아이디 · 이름·역할 · IP · 위치 · 디바이스 · 활동
3. 행 클릭 → 사용자 상세 활동 다이얼로그
   - 4개 카테고리 탭: 전체 / 로그인 / 슬라이드 조회 / AI 분석
   - 각 카테고리에 카운트 배지
4. "체인 검증" 버튼 → HMAC 체인 무결성 일괄 검증 (변조 감지)

---

## 28. 자주 발생하는 문제

| 증상 | 해결 |
|------|------|
| 로그인 후 빈 화면 | 토큰 만료 — 새로고침 또는 재로그인 |
| 첫 슬라이드가 흐릿하게 뜸 | 백그라운드 타일 생성 중 — 진행률 100% 까지 대기 |
| Hamamatsu 슬라이드 색이 옅어 보임 | 우측 "NDP 색보정" ON |
| AI 결과가 동일 | 캐시 hit — 관리자에게 캐시 리셋 요청 |
| 잠금 (5회 실패) | 30분 대기 또는 admin 잠금 해제 |
| MFA 코드 안 맞음 | 휴대폰 시계 자동 동기화 켜기 |
| 업로드 중간에 중단 | 같은 파일 재선택 시 청크 자동 재개 |
| PDF 출력 시 깨진 글자 | 한글 폰트 미설치 — IT에 요청 |

## 29. 데이터 백업·복구 (관리자용)

- **자동 백업 권장**: `users` + `audit_logs` 컬렉션 + `.secrets.json` 파일
- **별도 보관**: `.secrets.json` 은 일반 백업에 포함하지 말 것 — 별도 안전 보관
- **무결성 점검 (월 1회)**:
  1. 관리자 페이지 → 활동 로그 → "체인 검증"
  2. 임의 슬라이드의 "무결성 검증" (SHA-256)
- **복구 시**: MongoDB restore + `.secrets.json` 복원 → 재시작
